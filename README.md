# Karing Node Doctor

ابزار محلی برای تست خودکار نودهای Karing و ساخت خروجی فقط از نودهای سالم.

برنامه نودهای موجود در پروفایل‌های Karing را می‌خواند، در صورت فعال بودن منابع اینترنتی کانفیگ تازه دریافت می‌کند، همه را با موتور sing-box به‌صورت موازی تست می‌کند و در نهایت دو خروجی تمیز روی آدرس محلی ارائه می‌دهد: ساب‌سکریپشن sing-box برای Karing و لینک‌های v2ray برای v2rayN (با افزودن خودکار به پایگاه‌داده) یا v2rayA. یک داشبورد وب فارسی وضعیت تست، نودها، منابع، همگام‌سازی Karing و حالت TUN را نشان می‌دهد.

## ویژگی‌ها

- خواندن مستقیم پروفایل‌های Karing از دیسک (بدون نیاز به API کدینگ)
- دریافت روزانهٔ کانفیگ از منابع اینترنتی (اختیاری و قابل خاموش‌کردن)
- تست موازی نودها با sing-box و ثبت تأخیر هر نود
- حذف خودکار نودهای ناموفق پس از چند خطای متوالی و انقضای نودهای سالم
- حذف نودهای واقع در روسیه از تست و ساب‌سکریپشن (بر اساس محدوده‌های IP و بررسی آنلاین کشور سرور)
- ساخت ساب‌سکریپشن به فرمت sing-box با توکن تصادفی
- ساخت لینک‌های v2ray (vless / vmess / trojan / shadowsocks / hysteria2 / socks / http)
- افزودن خودکار اشتراک به v2rayN و به‌روزرسانی ساعتی آن بدون Import دستی
- نمایش و تغییر حالت TUN کیارینگ از داشبورد (نوشتن `tun.enable` در فایل تنظیمات با نسخهٔ پشتیبان)
- داشبورد وب با نمایش نودهای سالم، ناموفق‌ها، تاریخچه و وضعیت همگام‌سازی Karing
- اجرای خودکار دوره‌ای و امکان اجرای دستی
- اجرا در پس‌زمینه به‌همراه اجرای خودکار هنگام ورود به ویندوز (قابل غیرفعال‌سازی)

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- Node.js نسخه ۱۸ به بالا (برای افزودن خودکار به v2rayN: نسخه ۲۲.۵ به بالا)
- Karing نصب‌شده روی همان سیستم
- فایل `core\sing-box.exe` از [انتشارهای sing-box](https://github.com/SagerNet/sing-box/releases) — به دلیل حجم، در مخزن قرار ندارد

## راه‌اندازی

1. مخزن را دریافت کنید و فایل sing-box را در پوشهٔ `core` قرار دهید.
2. برنامه را اجرا کنید:

```bat
start.bat
```

یا:

```bat
npm start
```

3. داشبورد روی [http://127.0.0.1:3210](http://127.0.0.1:3210) باز می‌شود.
4. در Karing به بخش My Profiles بروید و آدرس ساب‌سکریپشن نمایش‌داده‌شده در داشبورد را به‌عنوان پروفایل remote از نوع sing-box اضافه کنید.
5. در ویرایش همان پروفایل، **Update Interval** را روی ۱ ساعت بگذارید تا Karing خودکار تازه بماند.

> پوشه‌های `data/` و `core/` در git نادیده گرفته می‌شوند؛ `data/state.json` شامل توکن ساب‌سکریپشن و نتایج تست شماست.

## افزودن خودکار به v2rayN

کارت «افزودن خودکار به v2rayN» در داشبورد، آدرس `/v2ray/<token>.txt` را مستقیم در پایگاه‌دادهٔ v2rayN (`guiConfigs/guiNDB.db`) ثبت می‌کند؛ بدون Import دستی و بدون بازکردن منو. پس از ثبت، v2rayN هر ساعت خودش اشتراک را می‌خواند و فقط نودهای سالم تازه را نگه می‌دارد.

- برنامه پوشهٔ v2rayN را خودکار پیدا می‌کند (ابتدا مسیر پروسهٔ در حال اجرا، سپس Desktop / Downloads / Documents / Program Files).
- اگر v2rayN موقع ثبت باز باشد، اشتراک در حافظهٔ آن نیست؛ یک‌بار کامل ببندید و باز کنید.
- برای حذف، همان دکمه را بزنید؛ فقط ردیف اشتراک این برنامه و نودهایش پاک می‌شود.
- v2rayN لینک‌های `http://` را از اشتراک وارد نمی‌کند؛ داشبورد تعدادشان را جدا اعلام می‌کند.
- نوشتن فقط با ماژول داخلی `node:sqlite` انجام می‌شود و به Node.js ‏۲۲.۵ یا بالاتر نیاز دارد (در نسخه‌های پایین‌تر، کارت پیام توضیح می‌دهد و بقیهٔ برنامه کار می‌کند).

همین آدرس برای v2rayA هم قابل استفاده است؛ فقط باید دستی **Servers → Add → By subscription link** را بزنید. نودهایی که xray پشتیبانی نمی‌کند (مانند `anytls`، `tuic`، `hysteria` v1، `wireguard`) از این خروجی حذف می‌شوند و تعدادشان در کارت مشخص است. چون سرویس فقط روی `127.0.0.1` گوش می‌دهد، v2rayN و v2rayA باید روی همان ویندوز اجرا شوند.

## حالت TUN

کارت «حالت TUN» مقدار `tun.enable` را از `karing_setting.json` می‌خواند و با دکمهٔ همان کارت آن را تغییر می‌دهد. قبل از هر نوشتن، فایل پشتیبان در همان پوشه ساخته می‌شود و بعد از نوشتن، مقدار ذخیره‌شده دوباره خوانده و تأیید می‌شود. Karing تنظیمات را در حافظه نگه می‌دارد، بنابراین بعد از تغییر باید Karing کامل بسته و دوباره باز شود (و مجدد متصل شود) تا TUN اعمال گردد؛ اگر برنامه در حال اجرا باشد، داشبورد هشدار می‌دهد.

## تنظیمات

تنظیمات از طریق داشبورد قابل تغییر است: بازهٔ اجرای خودکار، سقف زمان تست، تعداد تست هم‌زمان، سقف نودهای خروجی، تعداد خطا تا حذف، مدت اعتبار نود سالم، منابع اینترنتی و پروفایل‌های فعال.

## متغیرهای محیطی

| متغیر | کاربرد | پیش‌فرض |
| --- | --- | --- |
| `KND_PORT` | پورت داشبورد | `3210` |
| `KND_STATE_DIR` | مسیر ذخیرهٔ وضعیت | `data/` |
| `KND_KARING_DIR` | مسیر داده‌های Karing | `%APPDATA%\karing\karing` |
| `KND_CORE` | مسیر فایل sing-box | `core\sing-box.exe` |
| `KND_V2N_DIR` | مسیر پوشهٔ v2rayN | خودکار پیدا می‌شود |
| `KND_V2N_DB` | مسیر مستقیم فایل `guiNDB.db` | خودکار پیدا می‌شود |
| `KND_NO_AUTOSTART` | `1` = غیرفعال‌کردن اجرای خودکار هنگام ورود | — |

## ساختار

```
app.js          سرور HTTP، API و هماهنگی دوره‌ها
lib/            تست، خواندن Karing، ساب‌سکریپشن، لینک v2ray، پایگاه‌داده v2rayN، جغرافیای سرور، زمان‌بند، منابع اینترنتی
public/         داشبورد وب (HTML/CSS/JS)
core/           محل قرارگیری sing-box.exe (در مخزن نیست)
data/           وضعیت و تنظیمات (در مخزن نیست)
```

## نکته

کشور سرورها ابتدا با فهرست آفلاین محدوده‌های روسیه (`lib/geo/ru-v4.txt`) و در صورت نیاز با سرویس عمومی [ip-api.com](https://ip-api.com) بررسی می‌شود؛ فقط آدرس IP سرورها برای تعیین کشور ارسال می‌شوند. این ابزار فقط برای استفادهٔ شخصی و مدیریت کانفیگ‌های خودتان است. برای نودهای عمومی، قوانین منابع را رعایت کنید.
